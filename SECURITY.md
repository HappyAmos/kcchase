# Security Policy

## Supported Versions

Only the latest release and the `main` branch receive security fixes:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| `0.1.x` | :white_check_mark: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, report them privately using GitHub Security Advisories:

- https://github.com/HappyAmos/kcchase/security/advisories/new

Please include as much detail as possible:
- A clear description of the vulnerability and potential impact.
- Steps to reproduce or a proof of concept.
- Your OS, terminal emulator, and `kcchase --version` output.

## Response Timeline

- **Acknowledgment:** Within 72 hours of submission.
- **Triage & Update:** Within 7 days with an assessment and remediation plan.
- **Disclosure:** Coordinated disclosure once a fix is released on `main`.
